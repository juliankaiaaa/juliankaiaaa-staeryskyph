# Weekly reports

Five minutes a week. Add a new section at the top; never edit an old one.

The value is entirely in writing them **while it is happening**. What took four
hours and why is invisible a month later, and it is exactly what your journal
needs.

---

## Week of September 14, 2026

**What I worked on:**

- Started planning the final concept and overall direction of the Staery Sky PH portfolio website.
- Began organizing the content and sections that I wanted to include.
- Started gathering design inspiration and references for the website.

**What clicked:**

- I realized that creating a mockup first would help me understand what I wanted the website to look like.
- Having a clear design helped me have a better idea of what I needed to build.

**What I'm still stuck on:**

- I was still unsure how to start the coding part and how to turn my mockup into an actual website.
- I was also having a hard time deciding on the layout, fonts, colors, and overall design.

## Week of September 23, 2026

**What I worked on:**

- Started coding the Staery Sky PH website based on my mockup.
- Added the brown polka-dot background and pink design.
- Created the Home, About, Services, and Connect sections.
- Added the navigation bar and website content.
- Worked on the spacing, sizes, and fonts.
- Started working on the GitHub Pages setup and project documentation.

**What clicked:**

- I started to understand how a Figma design can be turned into actual code.
- I realized that CSS controls a lot of the visual parts of the website.
- Seeing the website appear in the browser helped me understand the connection between the code and the actual design.

**What I'm still stuck on:**

- Coding is still quite challenging for me, especially when I have to figure things out on my own.
- I still get confused with CSS, especially with spacing, sizing, and positioning.
- I was still learning how to build the other pages.
- I also had difficulty understanding how the backend and API would work.
